## 🔒 Understanding Access Bits

Access Bits control the permissions of a Mifare Classic card. Each Byte represents different rights:

- **Byte 6:** Read rights.
- **Byte 7:** Write rights.
- **Byte 8:** Special rights (like changing passwords).

You can use this tool to see how each bit affects user permissions. Understanding these rights can help you manage your cards better.
